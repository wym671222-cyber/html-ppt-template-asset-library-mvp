## 完成内容

1. 新增 `SecurePreviewRenderer`。它先完整验证 P03 v1 package，再写入随机、权限受控的临时目录；临时 HTTP server 只绑定 `127.0.0.1`，使用随机 URL token 且只响应 manifest 声明的 HTML/CSS。
2. Chromium 每次使用全新空 storage context，不使用宿主 profile/cookie；禁用 JavaScript、service worker 与下载。所有 page request 都经过默认拒绝 allowlist，只放行当前 preview origin 上无 query 的声明资源 GET。strict CSP、DOM/cookie/popup 回读是额外防线。
3. `PreviewArtifactRepository` 从已验证 `TemplateVersion.content_object_digest` 回读 P04 CAS，并重验 digest、version identity、P03 契约与规范序列化；不接受路径穿越、未声明资源、脚本、外链、CSS fetch、iframe、表单或新窗口内容。
4. 单个 `template-preview` Job 生成 1280×720 preview PNG 和 320×180 thumbnail PNG。输出格式/尺寸及安全诊断验证成功后，两者以 SHA-256 追加写入 CAS，再在同一 SQLite 事务中登记派生物；Job 的成功 output 固定为 preview digest。
5. 提交 `0002_p05_preview_derivatives.sql`。`template_preview_derivatives` 以 version/source/renderer/kind 固定派生身份；外键、唯一约束和触发器拒绝未验证 source、非 PNG、UPDATE/DELETE 及同 identity 的冲突输出。
6. P04 Job claim 增加可选类型过滤，原有无过滤行为保持不变；P05 Worker 不会消费其他 Job。策略/输入失败不可重试，Chromium 瞬态错误保留 P04 retry/lease/recover 语义。
