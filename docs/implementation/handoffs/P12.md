## 交付

1. `0005_p12_auth_core.sql` 和 Drizzle journal 新增无邮箱 `users`、仅存 token hash 的 `sessions`、只存 key hash 的 `auth_throttle`；约束 username 正规/NOCASE、两种 role、三种 status、唯一 admin、七天绝对过期、session 不可更新、改密/禁用后删除会话。
2. `password.ts`、`users.ts`、`sessions.ts`、`cookie.ts`、`throttle.ts` 提供 P13 可复用的底层能力：10–128 字符密码、Argon2id 至少 19 MiB/t=2/p=1、256-bit 随机 token + SHA-256 DB 索引、不滚动七天 session、严格 `__Host-ppt_session` Cookie、会话撤销和 SQLite 持久限流。
3. 共享 `User/UserRole/UserStatus/AuthSession` 改为 username-only 内部类型；不暴露 `password_hash`、raw token 或 Cookie。
4. 移除 `lucia` 与 `@lucia-auth/adapter-drizzle` 的 manifest/lockfile/安装树，删除 Lucia 组合模块；保留的旧 auth/admin 模块与 middleware 为 fail-closed 404，活动 composition root 未挂载任何 P13 端点。
5. 迁移器增加目标 trigger allowlist、未知/缺失 trigger 先备份后拒绝、迁移后精确表/trigger/quick/FK 复核；P09 recovery 由目标表和 journal 自动纳入三个身份表与第六条 ledger。
6. `tests/p12-auth-core.test.ts` 以及更新的 P02–P09 unit/E2E 断言覆盖空库/既有五迁移库/重复迁移、旧 trigger SQL/业务计数不变、未知 schema、密码 9/10/128/129、重复 username/第二 admin、token 篡改/过期、恶意 Cookie/Origin、撤销、限流重启和恢复脱敏。
