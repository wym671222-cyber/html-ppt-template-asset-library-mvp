## 完成内容

1. 新增 `AssetLibraryCatalog` 只读查询端口。它只选择 active asset、所属 verified/available current version，以及 source digest 和 renderer identity 完全一致、数据库登记媒体类型均为 `image/png` 的 P05 preview/thumbnail 完整对。搜索、分类、多标签、limit、facet 与稳定排序都参数化且有界。
2. 活动 Hono composition root 仅新增 `GET /api/catalog` 和 `GET /api/catalog/assets/:assetId/:kind`。catalog 明确接收固定 `OwnerContext`；PNG 路由只接受受限 asset id 和 `preview|thumbnail`，不接受 digest、客户端路径、`file:`、URL 或 query。
3. PNG 回读从 P05 登记的 content digest 进入 `LocalContentStore`，重新计算 SHA-256，并复核 CAS canonical relative path、数据库 byte size、`image/png`、PNG 签名及固定尺寸。missing、篡改、非 PNG 或元数据不一致返回受控错误，不泄露对象 digest/路径。
4. Web 根页实现三栏核心界面：左侧搜索/分类/标签，中间卡片与确定性选择，右侧版本/摘要/分类/标签/renderer 和安全 preview；加载、空库、无结果、错误恢复、图片失败、重置、方向键/焦点与基础响应式均有明确状态。
5. Web 通过两个固定同源 GET 代理消费 API JSON/PNG；上游地址只能是 loopback HTTP origin。CSP 去除外部字体与 data image，限定同源 connect/image 并禁止 frame/object/form；P06 源码无 HTML 注入、iframe/srcdoc/blob/外部 URL 或 cookie 依赖。
6. P02/P06 Playwright 配置都自带隔离 loopback server。P06 fixture API 只使用仓库内 P03 模拟包，并通过真实 `SecurePreviewRenderer`/Google Chrome 生成 P05 PNG，不接触 sibling 真实资产或实际目标库。
