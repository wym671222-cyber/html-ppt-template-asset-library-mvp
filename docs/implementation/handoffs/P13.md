## 交付

1. `AuthApplicationService`、`AuditEventWriter`、活动 auth/admin routes 与 session/admin middleware 完成 username-only 注册待审批、登录、会话回读、退出、改密、用户列表、审批、禁用与重置闭环。
2. 注册只产生 pending member 且不产生 session；登录先验密码，错误/未知统一 `INVALID_CREDENTIALS`，正确后才区分 `ACCOUNT_PENDING|ACCOUNT_DISABLED`，只有 active 用户可建立 P12 固定七天会话。
3. 管理端仅对有效 admin session 且 `must_change_password=false` 可达；middleware 与 service 双层对强制改密管理员稳定返回 403 `PASSWORD_CHANGE_REQUIRED`，只保留 session/logout/change-password。审批只允许 pending member→active，管理员不能禁用自己，路由无 role 提升能力。唯一 admin 由既有 SQLite 部分唯一索引与 bootstrap immediate transaction 双重保证。
4. reset-password 仅在该次 `Cache-Control: no-store` JSON 响应返回 24 字符加密随机临时密码，DB 只存 Argon2id hash；同时设 `must_change_password=true` 并撤销全部 session。管理员自重置或被重置后以临时密码登录也不能调用 admin API；改密成功后设 false、再次撤销全部 session 并清 Cookie，使用新密码重新登录才恢复管理权限。
5. 全部 API 写请求收紧为精确 Origin：生产固定 `https://ppt.ajjy-ai.site`，测试/本地仅允许明确 loopback。Presentation/Recovery BFF 同步传递受控 Origin，未更改 Owner 或业务权限语义。
6. 注册使用 3/IP/小时；登录同时使用 IP+username 和 IP 桶。全部复用 P12 SQLite `auth_throttle` 并只存 key hash，已以关闭/重开隔离 DB 证明阻断持久。API 只绑定 loopback，忽略任意 `Forwarded`/`X-Forwarded-For`/`X-Real-IP`；仅接受受控内部跳点的单一 `X-PPT-Client-IP`，值必须是单个合法 IP，否则按 `127.0.0.1` 计桶。
7. append-only `audit_events` 覆盖成功/失败身份和管理动作、bootstrap 及 Origin 拒绝，只写固定动作码、entity id 和无秘密诊断码。raw password/session token/Cookie/临时密码未进入 audit、diagnostic、日志或错误。
8. `pnpm seed:admin -- <username>` 仅允许一个 username 参数，需 TTY 两次隐藏密码输入，不提供命令行明文密码通道；非交互终端失败关闭，仅零管理员时创建唯一 active admin。CLI 入口已显式纳入 API `tsconfig.json`，标准 `pnpm build` 会类型检查并产出 `dist/auth/bootstrap-admin.js`。
9. `tests/p13-auth-approval.test.ts` 覆盖接口契约、审批/禁用/密码状态机、bootstrap/单 admin、CLI 标准构建产物、管理员强制改密负向与恢复正向、临时密码一次显示边界、全 session 撤销、Origin、受信客户端 IP 边界、跨重启限流、无 email 字段和认证失败业务 DB 不变。
