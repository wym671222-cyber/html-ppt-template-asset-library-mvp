## 实现内容

1. 导出仓储发布 `html-presentation-export/v3` 与 `html-presentation-export-package/v3`。索引页仅引用受控 ZIP 内的 `slides/*.html` 与去重后的 `assets/*.png`，每个 slide 通过精确 `sandbox="allow-scripts"` iframe 按需隔离；manifest 保留固定 Presentation revision、不可变 `template_version_id`、源摘要、预览/缩略图双派生物和 package 文件摘要。
2. v1 模板保留已声明的合法 `data:image/{png,jpeg,webp,gif};base64`（严格 MIME/字节签名、规范 base64、2 MiB 上限），同时继续拒绝未声明、协议相对、URL/file/blob/javascript、路径穿越和活动元素；HTML/CSS data:image 均走同一白名单校验。
3. v2 源包在导出前再次经过 P01 policy、规范序列化、固定 source digest 和 `INTERACTIVE_TEMPLATE_V2_ALLOWLIST` 校验；运行包复用 P02 supervisor/inner opaque origin、`ready/error/replay/reset` schema，离线写入与同值的 CSP meta，双层 iframe 均只有 `allow-scripts`，不含 `allow-same-origin`。PresentationItem 槽位快照在受 nonce 保护的 bootstrap 内应用。
4. 保留历史 `html-presentation-export/v2` / package v2 读取与完整 ZIP/hash/manifest 验证；新写入一律 v3。缩略图按摘要去重，重复导出按 immutable fingerprint 幂等，所有渲染、allowlist、revision 或 hash 失败均发生在 CAS/DB 写入前。
5. `assertSafeExportHtml` 保留严格默认模式；v3 仅额外接受受控 slide iframe 和合法 data:image，runtime 文件再验证 CSP、opaque protocol marker、inner data document、资源和 sandbox 边界。
