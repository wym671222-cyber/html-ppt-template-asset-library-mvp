# PocketBay 加密备份与恢复手册

## 备份

1. 管理员进入首页“加密备份与恢复演练”，点击“生成备份清单”。
2. 输入不少于 14 个字符的独立备份口令，点击目标备份的“加密下载”。
3. 将 `.pba` 文件保存到异地存储；口令与文件分开保管。

下载前，服务端会重新校验 SQLite、migration、CAS、预览派生物和导出物。明文 ZIP 仅进入当前浏览器内存，随后以 PBKDF2-SHA-256（600,000 次）派生的 AES-256-GCM 密钥加密；口令不会发送到服务端。

## 恢复

1. 管理员选择 `.pba` 并输入口令，点击“解密并导入”。
2. 浏览器完成认证解密，再把受控 ZIP 发送到 loopback API；服务端拒绝未声明文件、路径逃逸、哈希不符、未知表和不匹配 migration。
3. 点击“隔离恢复演练”。系统写入新的 `/data/recovery-drills` 子目录并再次检查数据库、CAS、预览和导出，不覆盖当前状态。
4. 演练通过后，可点击“准备重启激活”，按提示输入完整确认串。
5. 在 PocketBay 控制台重启容器。API 打开数据库前会第三次验证恢复结果、合并内容寻址对象、原子切换数据库，并把原数据库保留在 `/data/recovery-rollbacks`。

激活失败时服务保持失败关闭并尝试恢复原数据库；不会在运行中直接覆盖打开的 SQLite。激活后的备份不恢复旧会话，所有用户需要重新登录。

## 限制

- 单个归档最大 128 MiB，最多 5,002 个文件。
- 本机最多列出 20 个备份；清理由管理员在维护窗口另行执行。
- `.pba` 不是服务端托管的远程备份；管理员必须完成异地保存并验证文件可读取。
- 丢失口令无法恢复加密文件。
