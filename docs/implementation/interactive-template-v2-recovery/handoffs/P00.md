## 红测合同与结果

测试以 `mkdtempSync()` 创建隔离 SQLite、空 CAS、裸目录 backup root、restore root 和 activation request 路径：

1. 运行真实七项 migration，创建合法裸目录备份并记录源指纹、备份逻辑表状态与物理 SHA-256。
2. 只对备份 SQLite 切换 DELETE journal，设置 `page_size=8192` 并执行 `VACUUM`。
3. 断言所有非 SQLite 内部表及其有序行状态逐字相同、`quick_check=ok`、物理 SHA-256 已变化。
4. 调用当前 `LocalRecoveryService.inspectCurrent()`，捕获并精确断言 `Backup SQLite hash or size verification failed`。
5. 断言 restore 目录未创建、activation request 不存在、源数据库/CAS 指纹未变化；随后重新抛出原错误，使红测命令真实退出非零。
